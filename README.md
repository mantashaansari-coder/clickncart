## Git Commands I'm Practicing

| Command | Description |
|---|---|
| `git --version` | Check the Git version |
| `git config --global user.name "Your Name"` | Set your username |
| `git config --global user.email "you@example.com"` | Set your email |
| `git init` | Initialize a Git repository |
| `git status` | Check the status of files |
| `git add .` | Stage all changes |
| `git commit -m "message"` | Save changes in a commit |
| `git log` | View commit history |
| `git branch` | List branches |
| `git switch -c branch-name` | Create and switch to a new branch |
| `git clone repository-url` | Clone a repository |
| `git push` | Upload local commits to a remote repository |
| `git pull` | Download and integrate remote changes |

### How to add this README to your GitHub repository

1. Open your project folder in VS Code.
2. Create a new file named `README.md`.
3. Copy the content above and paste it into the file.
4. Save the file.
5. Open the terminal and run:

```bash
git init
git add README.md
git commit -m "Add Git learning README"
```

6. Create a new repository on GitHub.
7. Connect your local repository to GitHub and push your changes.

**Remember:** Git is the tool you use to track changes in your code, while GitHub is a platform where you can host Git repositories and collaborate with others.
